01 — The training set

Learning from the few we have measured.

Of 41,884 near-Earth asteroids, only 116 have both a measured spectral class and a measured albedo, the pairing the model needs to learn from. They are badly imbalanced: 83 stony, 29 carbonaceous, just 4 metallic. That imbalance shapes everything downstream, and we never hide it.

Each object is described by 8 features it already has: albedo, absolute magnitude, and six orbital-dynamics terms (semi-major axis, eccentricity, inclination, perihelion, aphelion, Tisserand parameter).

02 — The model

What reflectivity reveals.

A class-balanced random forest of 200 shallow trees votes on each asteroid's class. We keep the trees shallow and weight the classes so the model cannot simply memorize the training set or ignore the rare classes.

By far the strongest signal is albedo: dark carbonaceous rock reflects only a few percent of sunlight, bright stony rock far more. Orbital dynamics fill in the rest. It is physically sensible, not a black box.

03 — Testing without cheating

Never scored by a model that has seen it.

Every accuracy number is measured by leave-one-out cross-validation: train on 115 objects, predict the one held out, repeat 116 times. No object is ever scored by a model that trained on it.

Under one identical protocol, the random forest reaches 82% (leave-one-out), beating gradient boosting, logistic regression, and the “always guess stony” baseline. We picked the model the evidence picked.

Logistic regression trades raw accuracy for minority recall; the forest wins outright.
04 — Honest confidence

Calibrated, and willing to say “I don't know.”

A confidence number is only useful if it is true. Platt-scaling the probabilities cut the expected calibration error from 0.143 to 0.067, more than half, so a stated 80% really means about 80%.

Better still, the model can abstain. Keep only predictions above a confidence threshold and accuracy climbs from 78% toward 89% as low-confidence guesses drop out. Honest coverage beats confident error.

05 — Data-limited, not model-limited

More labels would still help.

The learning curve still climbs at the largest training size we have. A model that had saturated would flatten; ours is still rising at 92 objects. The bottleneck is labelled data, not the algorithm.

And the part that is learnable is already strong: drop the four metallic objects, where albedo genuinely cannot separate the class, and the carbonaceous-versus-stony decision hits 84.5%. The model is honest about the boundary it cannot draw.

06 — The infrared upgrade shipped

We added the infrared. It worked.

We cross-matched the catalogue to NEOWISE (visible and near-infrared albedo for 141,920 bodies) and the SDSS colour survey, and retrained with those features in play. On the same leave-one-out test, accuracy rose from 72% to 78%, a +6 point gain, with carbonaceous recall climbing too.

Metallic recall is still 0%, and now we know precisely why: it is no longer a feature problem, the infrared that separates metal is in the model. It is a label problem. You cannot teach a class from 4 examples. That is the last lever, and it is the next paper.

07 — The roadmap

The best things we can do, and what each one needs.

Ranked by impact. The first two are the difference between a good screening prior and a genuinely trustworthy characterization.

1

Add infrared + colour features shipped · +6 pts

Done. NEOWISE visible and near-infrared albedo plus SDSS colour, cross-matched and retrained, lifted leave-one-out accuracy from 72% to 78% and improved carbonaceous recall. The infrared that separates metallic is now in the model.

Result: +6 points, reproduced on the live dataset. Metallic still pending more labels (item 2).
2

Grow the labelled set high impact

The learning curve says we are data-limited. More measured spectra mean more reliable boundaries and the option of finer classes than C / S / M.

Needs: ingest and cross-match more spectral surveys (SMASS II, Bus-DeMeo / MITHNEOS, Gaia DR3 reflectance) to lift the training set well past 116.
3

Ship calibrated probabilities + abstention proven here

The experiments already show calibration halves the error and abstention lifts accuracy to 89%. This is about putting both into the live product, not inventing anything new.

Needs: wire Platt-scaled probabilities into the serving model and expose an “indeterminate” state below a chosen confidence threshold (about 0.60).
4

Conformal prediction sets

Instead of one forced label, return an honest set, “C or S, 90% covered.” A natural upgrade once probabilities are calibrated.

Needs: a held-out calibration split and a conformal wrapper around the classifier.
5

Revisit gradient boosting as data grows

The forest wins at 116 objects, but boosting usually overtakes on larger tabular sets. Worth re-running the comparison once the labelled set is bigger.

Needs: the larger training set from items 1 and 2, then re-run the same cross-validated bake-off.
