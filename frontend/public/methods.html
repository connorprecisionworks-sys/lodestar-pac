00Abstract

Lodestar ranks near-Earth asteroids by estimated resource value cross-referenced with accessibility, predicts the composition of objects that have never been spectrally measured, and computes real launch windows and transfer trajectories. It is built to scale to the modern flood of newly discovered asteroids, where hand-curation cannot keep pace. Every figure it produces is an estimate with an explicit uncertainty band and a provenance tag (measured, ML-predicted, or assumed); it never presents an inference as a measurement.

01System overview

The pipeline is five independently testable layers:

  • Data ingestion — orbital elements, sizes, albedos, and measured spectral types from the JPL Small-Body Database, joined with the Asterank baseline. Normalized to a local columnar store of 41,884 objects.
  • ML characterization — predicts compositional class and calibrated confidence for objects with no measured spectrum.
  • Astrodynamics — analytic two-body propagation plus a Lambert solver and porkchop sweep for launch windows and transfer Δv.
  • Ranking & value — a resource-based value model and a composite value-versus-accessibility score with user-adjustable weights.
  • Interface — a browser console with a ranked table, 3D orbit and catalog views, real shape models, and per-object mission feasibility.

02ML characterization (the differentiator)

The problem

Of 41,884 near-Earth asteroids, only 267 have a measured taxonomic class. The overwhelming majority are uncharacterized. The model predicts an object's compositional complex — C carbonaceous, S stony, M metallic — with calibrated uncertainty, from the features that exist for far more objects.

Training data & class balance

Labels come from measured Bus-DeMeo / Tholen taxonomy. Albedo (reflectivity) is the physically strongest available feature: dark surfaces indicate carbon-rich bodies, bright surfaces stony ones. Only 116 objects have both a label and a measured albedo, and the classes are heavily imbalanced:

Model

A class-balanced random forest (200 trees, depth-capped to avoid memorizing the small set) over eight features: albedo, absolute magnitude, semi-major axis, eccentricity, inclination, and three dynamical features (Tisserand parameter relative to Jupiter, perihelion, aphelion). The dynamical features were retained only because leave-one-out testing showed they improved accuracy (82% vs 80% without them).

Honest limitations

  • Metallic asteroids cannot be identified from albedo. The X-complex is albedo-degenerate (bright enstatite and dark primitive bodies overlap with metals), and only 4 labeled M-types exist. The model reports M as a weak prior only — never a confident call. Reliable metal identification requires radar or spectra.
  • Coverage is capped by albedo. Only ~1,200 of 41,884 objects (3%) have a measured albedo, so the model is silent on the rest. This is the central bottleneck.
  • Space weathering and grain-size effects bias reflectance-based inference, a known limitation in the literature.
  • The training set is small and biased toward bright, well-observed objects.

The mitigation for all of the above is the same and is built in: uncertainty is a first-class output, never hidden. The path past the coverage cap is multi-band colors (SDSS Moving Object Catalog and, at scale, Rubin Observatory), which exist for hundreds of thousands of objects; the pipeline is built to ingest them.

03Astrodynamics & launch windows

Heliocentric state vectors are propagated analytically under two-body Keplerian motion. Transfers are solved with a universal-variable Lambert solver (Curtis, Algorithm 5.2). A porkchop sweep over departure date × time-of-flight finds the minimum-Δv launch window, including the launch burn from a 300 km parking orbit (Oberth-correct) and the arrival rendezvous burn.

Validation: the Lambert solver reproduces Curtis Example 5.2 to four decimal places, and the porkchop recovers asteroid 433 Eros's optimal rendezvous Δv at 6.10 km/s against the published Benner value of 6.11 km/s. The earlier closed-form screening proxy gave 7.6, so the Lambert engine is a genuine accuracy improvement, not a cosmetic one.

This is screening-grade: two-body analytic ephemerides, not the Horizons-precision n-body integration a real mission requires. It is explicitly a tool for deciding which asteroid and roughly when, not for flying the spacecraft.

04Value & resource model

Value is built up from composition, not asserted as a single dollar-per-kilogram. Each complex maps to recoverable mass fractions of water, iron-nickel, and platinum-group metals, each with a coarse in-space value per kilogram; mass comes from size and an assumed bulk density. This yields per-object resource tonnages and a headline value with an explicit uncertainty band. The uncertainty widens by provenance tier: tightest for measured composition, wider for ML-predicted, widest for assumed, and further by how the size was derived.

These are deliberately order-of-magnitude figures for triage (is this worth a closer look), not appraisals. The model is the reason the famous targets surface correctly: the lowest-Δv high-value objects it ranks are the real mission destinations — Apophis, Itokawa, Bennu, Eros.

05Mission feasibility

Each object's Δv is translated into a fuel-and-effort story via the Tsiolkovsky rocket equation: the propellant mass fraction for a chemical engine versus an electric/ion engine, plus a feasibility tier. At Eros's 6.1 km/s, a chemical stage must be 86% propellant by mass; an ion stage, 19% — which is why deep-space missions go electric.

06The honesty framework

Every estimate carries provenance and uncertainty. Composition is tagged measured, ml-predicted, or assumed. Δv is tagged benner (published) or computed. Value and resources ship as ranges. The litmus test for every feature is whether it helps decide which asteroid to study or visit next; anything drifting toward "fly the mission" is out of scope.

07Limitations & future work

  • ML coverage is albedo-limited; multi-band colors (SDSS, Rubin) are the path to the uncharacterized majority.
  • Metallic identification needs radar/spectra, not reflectance.
  • Trajectories are two-body screening-grade; Horizons-precision ephemerides and rendezvous/low-thrust optimization are future work.
  • Value figures are order-of-magnitude, not appraisals.
